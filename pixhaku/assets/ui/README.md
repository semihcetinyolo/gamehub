# Pixhaku pixel UI

The active game theme uses warm cream, terracotta, ochre and leaf green. Buttons, frames, badges and progress meters have stepped pixel edges. Gameplay's bottom control strip contains only Hint; Help is available in Settings.

- `pixel/*.svg`: code-native icons drawn on a 16×16 pixel grid.
- `pixel-theme.css`: readable copy of the current game skin. The playable HTML embeds this CSS, its font and its icons.
- `PressStart2P-Regular.ttf`: Press Start 2P from the official Google Fonts repository, https://github.com/google/fonts/tree/main/ofl/pressstart2p
- `PressStart2P-OFL.txt`: accompanying SIL Open Font License.

The previous Finding Animals PNG sprites and rounded font are retained here as reference files. They are no longer embedded or used by the current UI. Puzzle artwork is unchanged.
